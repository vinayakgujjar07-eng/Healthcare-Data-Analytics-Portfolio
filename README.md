# &#x20;Featured Project: Healthcare Analytics

# 

# An end-to-end healthcare analytics project using hospital admission data to analyse patient demographics, medical conditions, billing patterns, insurance providers and hospital operations.

# 

# &#x20;Project Highlights

# 

# \- Analysed 55,500 original hospital admission records.

# \- Identified and removed 534 duplicate records.

# \- Identified invalid negative billing values and handled them during cleaning.

# \- Created a cleaned dataset containing 54,966 records.

# \- Performed data analysis using SQL and Python.

# \- Developed an interactive Power BI dashboard.

# 

# &#x20;Key Performance Indicators

# 

# | KPI | Result |

# | Total Admissions | 54,966 |

# | Total Revenue | 1.404 Billion |

# | Average Billing | 25,594.63 |

# | Average Patient Age | 51.54 Years |

# | Average Length of Stay | 15.50 Days |

# | Distinct Hospitals | 39,876 |

# 

# Currency is unspecified in the source dataset. The dataset appears synthetic, so these figures should not be interpreted as actual hospital performance.

# &#x20;Project Workflow

# 

# My approach to healthcare analytics projects follows this workflow:

# 

# 1\. Data Collection: Obtain and understand the dataset.

# 2\. Data Profiling: Examine data structure, quality, missing values and duplicates.

# 3\. Data Cleaning: Handle duplicate records, invalid values and inconsistencies.

# 4\. Exploratory Analysis: Identify patterns, trends and relationships.

# 5\. Business Analysis: Calculate KPIs and evaluate relevant business metrics.

# 6\. Visualisation: Develop charts and interactive dashboards.

# 7\. Documentation: Communicate findings, limitations and business insights.
